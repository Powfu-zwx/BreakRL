时序差分学习

动态规划需要全知全能的环境模型，蒙特卡洛需要漫长等待剧集终结。时序差分学习跨越了这一鸿沟：它在完全无知的黑暗中，用一个猜测去修正另一个猜测。

预测的两难：等待真相还是当场猜度

设想你每天开车去公司上班。今天行驶到中途高架桥时，你目睹前方发生多车连环追尾，道路被彻底堵死。此时你该如何修正最初对「预计到达时间」的预测？

强化学习的三大家族： 动态规划（DP）基于完备转移模型向后推演；蒙特卡洛（MC）不需模型，但必须等待整段真实轨迹落幕；时序差分（TD）集两家所长：既不需要物理模型，也无需等待结局。

纯粹的蒙特卡洛思维是冷酷的：在车轮彻底停入公司地库、关掉引擎抬头看表之前，它拒绝调整任何数字。这种估计是绝对无偏的，但你必须苦等整个事件彻底闭环，并且路上哪怕偶遇一个随机红灯的波动，都会叠加进最终的高方差目标里。

而时序差分的做法更贴合人类直觉：看到车祸的那一瞬间，你用已经消耗的时间，加上对前方拥堵路段的最新估计，当场重估整体耗时。时序差分学习绝不等结局落幕；它用眼前刚刚发生的即时反馈，加上对下游未来的新鲜猜测，原地修正先前的猜测。

TD(0) 算子：原地自举的误差修正

为了在数学上清晰对比，我们列出评估状态价值 $V(S_t)$ 的三种核心目标形式：

1. 蒙特卡洛方法（整轨样本更新）： 等到终止步 $T$，以整条轨迹兑现的真实折扣回报 $G_t$ 作为更新靶标：

$$V(S_t) \leftarrow V(S_t) + \alpha \left[ G_t - V(S_t) \right], \quad G_t = \sum_{k=0}^{T-t-1} \gamma^k R_{t+k+1}$$

2. 动态规划方法（全期望遍历）： 依赖完整的转移概率核 $\mathcal{P}(s' \mid s, a)$：

$$V(s) \leftarrow \sum_{a} \pi(a \mid s) \left[ \mathcal{R}(s, a) + \gamma \sum_{s'} \mathcal{P}(s' \mid s, a) V(s') \right]$$

3. TD(0) 学习（单步采样自举）： 仅从自然界中采样单一转移元组 $(S_t, A_t, R_{t+1}, S_{t+1})$，立即原地完成备份：

$$V(S_t) \leftarrow V(S_t) + \alpha \underbrace{\left[ R_{t+1} + \gamma V(S_{t+1}) - V(S_t) \right]}_{\delta_t \text{ (TD 误差)}}$$
贝尔曼映射的单次样本体现： TD 误差 $\delta_t = R_{t+1} + \gamma V(S_{t+1}) - V(S_t)$ 严格对应贝尔曼期望算子的单次自然界采样实现： $$\mathbb{E}_\pi[\delta_t \mid S_t = s] = \mathcal{T}^\pi V(s) - V(s)$$ 当且仅当 $V = v_\pi$ 达到真值时，TD 误差的数学期望恒等于零。

其中 $R_{t+1} + \gamma V(S_{t+1})$ 被称为 TD 目标（TD Target）。不同于蒙特卡洛必须求和到未来终点，TD 学习直接用当前对下一状态的估计值 $V(S_{t+1})$ 代替了未知的一切未来收益。这种用估计去修正估计的机制，被称为自举（Bootstrapping）。

偏差与方差：信用分配的连续谱系

蒙特卡洛与 TD(0) 构成了强化学习中最典型的偏差-方差权衡（Bias-Variance Trade-off）：

蒙特卡洛目标 (MC) 零偏差 · 高方差

以真实回报 $G_t$ 为目标。由于直接采自自然界真实终局，完全无偏；但整条长轨迹上每一步的随机扰动不断累积，方差巨大。

目标结构 $G_t = \sum_{k=0}^\infty \gamma^k R_{t+k+1}$
任务限制 必须为有限剧集（无法在线终身学习）
收敛阻力 慢（高方差要求极小步长 $\alpha$）
TD(0) 自举目标 极低方差 · 带有偏差

以 $R_{t+1} + \gamma V(S_{t+1})$ 为目标。继承了当前估计器 $V$ 的初始先验偏差；但通过截断后续整段轨迹噪音，大幅压缩方差。

目标结构 $R_{t+1} + \gamma V(S_{t+1})$
任务限制 完全在线支持（连续无休止任务）
收敛阻力 快（方差小，可耐受激进的步长 $\alpha$）

$n$ 步时序差分：统一的连续谱系

TD(0) 与蒙特卡洛并非水火不容的两极，它们是一个由规划步长 $n$ 参数化的连续谱系的端点：

$$G_t^{(n)} = R_{t+1} + \gamma R_{t+2} + \dots + \gamma^{n-1} R_{t+n} + \gamma^n V(S_{t+n})$$

随着 $n$ 从 $1$ 渐变到 $\infty$，$n$ 步 TD 在完全自举（TD(0)）与零自举（MC）之间平滑过渡。在工程实践中，适度折中的步数（如 $n=3$ 或 $n=5$）往往表现最佳：既积累了足够多的真实奖励稀释初始估计偏差，又及时截断了后续未知的方差雪崩。

从价值到控制：同策略与异策略的本质对决

当环境物理模型未知时，单纯估计状态价值 $V(s)$ 无法直接转化为行动策略（若无法预测动作会导向何方，你根本无法评估 $\arg\max_a \sum_{s'} \mathcal{P}(s' \mid s, a) V(s')$）。因此，无模型控制必须转向学习动作价值 $Q(s, a)$。

SARSA：同策略控制（On-Policy）

SARSA 严格评估并改进当前正在执行的真实策略（包含探索阶段的随机走样）：

算法规范 · SARSA (State-Action-Reward-State-Action) 同策略 TD 控制
  1. 在状态 $S_t$，依据行为策略（如基于 $Q$ 的 $\varepsilon$-贪心）挑出动作 $A_t$；
  2. 执行动作 $A_t$，观测即时回报 $R_{t+1}$ 与下一状态 $S_{t+1}$；
  3. 在状态 $S_{t+1}$ 下，依据同一行为策略预先抽选下一动作 $A_{t+1} \sim \pi(\cdot \mid S_{t+1})$；
  4. 执行同策略自举更新： $$Q(S_t, A_t) \leftarrow Q(S_t, A_t) + \alpha \left[ R_{t+1} + \gamma Q(S_{t+1}, A_{t+1}) - Q(S_t, A_t) \right]$$
  5. 递进状态与动作：$S_t \leftarrow S_{t+1}, \; A_t \leftarrow A_{t+1}$，循环往复。

Q-Learning：异策略控制（Off-Policy）

Watkins 在 1989 年斩断了“执行策略”与“评估策略”之间的硬性绑定，开创了 Q-Learning：

算法规范 · Q-Learning (Watkins, 1989) 异策略 TD 控制
  1. 在状态 $S_t$，依据行为策略（如 $\varepsilon$-贪心）执行动作 $A_t$；
  2. 执行动作 $A_t$，观测回报 $R_{t+1}$ 与下一状态 $S_{t+1}$；
  3. 强行假定未来永远采取全局最优决断，执行异策略自举更新： $$Q(S_t, A_t) \leftarrow Q(S_t, A_t) + \alpha \left[ R_{t+1} + \gamma \max_{a} Q(S_{t+1}, a) - Q(S_t, A_t) \right]$$
  4. 递进状态：$S_t \leftarrow S_{t+1}$，循环往复。

两者的本质差异在于对未来的预设：SARSA 预料到了自己未来仍会犯错探索，因而主动趋利避害；而 Q-Learning 在目标中假定从下一步起自己永远绝对理性。

SARSA（同策略·安全绕远） Q-Learning（异策略·极限贴边）

观察两名智能体的学习动态：

  • Q-Learning（红点）： 学会了紧贴悬崖边缘的最短最优路径（耗时仅 13 步）。因为它的更新采用 $\max_a Q$，其目标深信自己绝对不会失足；然而在训练探索期（$\varepsilon=0.1$），哪怕一次极小概率的随机手抖，就会直接跌落深渊，导致其训练期累计得分极端难看。
  • SARSA（绿点）： 学会了从顶部高位大范围迂回的保守安全路线。由于其更新直接代入了下一轮真实带探索的动作，紧贴悬崖的格子在数学期望上包含了高昂的失足代价，逼迫它向远离悬崖的安全纵深避险。
失败图鉴第 10 条 · 行为策略与评估协议错配

训练曲线的狼狈仅仅反映了行为策略（带有探索噪音）的表现，绝不代表学到的价值曲面的最终贪心能力。Q-Learning 在训练中频繁摔得粉身碎骨，但一旦在部署时关掉探索（$\varepsilon = 0$ 贪心评估），它所走出的正是无可挑剔的理论最优路径。

评估算法性能时切忌将训练期探索回报当作最终答卷：同策略追求在线安全稳健，异策略追求全局无妥协的最优极限。

失败模式：步长敏感度与致命三要素

时序差分放弃了蒙特卡洛纯粹的样本平均安全网，在换取惊人收敛速度的同时，也打开了数值脆弱性的大门：

失败图鉴第 11 条 · 对步长与多步设置的病态敏感

与蒙特卡洛在简单经验平均下必然单调渐近收敛不同，TD 自举更新每一步都在追逐一个移动靶标（$R_{t+1} + \gamma V(S_{t+1})$）。

若学习率 $\alpha$ 过大，下游估计的微小波动会被自举机制呈指数级回溯放大，导致价值曲面剧烈振荡；若 $\alpha$ 过小，自举传播又如泥牛入海。最优步长与环境谱半径及奖励尺度高度耦合，容错窗口极窄。

深度强化学习的致命三要素（The Deadly Triad）

当我们将 TD 从简单查表法推广至函数逼近（如深度神经网络）时，收敛保证荡然无存。同时满足以下三项条件时，系统极易发生灾难性数值发散：

  1. 函数逼近（Function Approximation）： 使用参数化网络表征价值 $V_\theta(s)$ 或 $Q_\theta(s, a)$；
  2. 自举估计（Bootstrapping）： 用下游估计值代替真实蒙特卡洛全回报；
  3. 异策略学习（Off-Policy Learning）： 在异于数据收集策略的分布上实施更新。

打破三要素中的任意一环即可夺回稳定性：蒙特卡洛丢弃自举，SARSA 丢弃异策略分布漂移，查表法丢弃函数逼近。

import numpy as np

class QLearning:
    """针对离散状态动作空间的异策略 TD 控制"""
    def __init__(self, num_states, num_actions, alpha=0.1, gamma=0.99, epsilon=0.1):
        self.Q = np.zeros((num_states, num_actions))
        self.alpha = alpha
        self.gamma = gamma
        self.epsilon = epsilon
        self.num_actions = num_actions

    def act(self, state):
        if np.random.rand() < self.epsilon:
            return np.random.randint(self.num_actions)
        return int(np.argmax(self.Q[state]))

    def update(self, s, a, r, next_s, done):
        target = r if done else r + self.gamma * np.max(self.Q[next_s])
        self.Q[s, a] += self.alpha * (target - self.Q[s, a])

class SARSA(QLearning):
    """评估实际探索策略的同策略 TD 控制"""
    def update(self, s, a, r, next_s, next_a, done):
        target = r if done else r + self.gamma * self.Q[next_s, next_a]
        self.Q[s, a] += self.alpha * (target - self.Q[s, a])

扩展阅读与经典文献

以下里程碑文献奠定了时序差分学习与无模型控制的基石：

  1. Sutton & Barto · Reinforcement Learning: An Introduction
    第 6 章：时序差分学习。TD 误差、自举机制与悬崖漫步动力学的经典阐释。
  2. Sutton (1988) · Learning to predict by the methods of temporal differences
    Machine Learning. 提出 TD($\lambda$) 理论并证明其在吸收马尔可夫链上的线性收敛性。
  3. Watkins & Dayan (1992) · Q-learning
    Machine Learning. 首次严格完成了 Q-Learning 几乎必然收敛至最优动作价值的数学证明。
  4. Rummery & Niranjan (1994) · On-line Q-learning using connectionist systems
    剑桥大学技术报告。形式化提出了用于在线动作控制的 SARSA 算法。
  5. Tsitsiklis & Van Roy (1997) · An analysis of temporal-difference learning with function approximation
    IEEE Transactions on Automatic Control. 阐明了带函数逼近的 TD 算法稳定性边界与数值发散风险。
