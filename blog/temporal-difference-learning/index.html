Temporal-Difference Learning

Dynamic programming requires an omniscient transition model; Monte Carlo requires waiting for eternity to end. Temporal-Difference learning bridges the chasm by updating a guess from a guess.

The Prediction Dilemma: Waiting vs. Guessing

Imagine predicting your commute time to work. Halfway along the highway, you encounter an unexpected multi-car collision that backs up traffic for miles. How should you adjust your arrival estimate?

The Three Paradigms: Dynamic Programming solves by planning over an explicit transition model. Monte Carlo learns model-free by waiting for terminal returns. Temporal Difference combines both: it learns from raw experience without a model, yet bootstraps without waiting.

A pure Monte Carlo mindset refuses to update anything until you park the car, glance at the dashboard clock, and compare the total time against your morning prediction. It is completely unbiased, but it forces you to wait until the episode concludes, absorbing all cumulative weather and traffic noise along the entire route into a high-variance target.

A Temporal-Difference approach revises the prediction immediately: at the moment of seeing the wreckage, you combine the elapsed travel time with your fresh estimate of the remaining delay. TD learning does not wait for the final outcome; it updates a prior guess using immediate empirical feedback coupled with a downstream guess.

The TD(0) Operator: Bootstrapping in Place

To crystallize the mathematical contrast, recall the three core update targets for evaluating a state value $V(S_t)$:

1. Monte Carlo (Full Trajectory): Waits for the terminal step $T$ and updates toward the realized discounted return $G_t$:

$$V(S_t) \leftarrow V(S_t) + \alpha \left[ G_t - V(S_t) \right], \quad G_t = \sum_{k=0}^{T-t-1} \gamma^k R_{t+k+1}$$

2. Dynamic Programming (Expectation Backup): Requires complete transition probabilities $\mathcal{P}(s' \mid s, a)$:

$$V(s) \leftarrow \sum_{a} \pi(a \mid s) \left[ \mathcal{R}(s, a) + \gamma \sum_{s'} \mathcal{P}(s' \mid s, a) V(s') \right]$$

3. TD(0) (Sampled Bootstrapping): Samples a single transition $(S_t, A_t, R_{t+1}, S_{t+1})$ from nature and updates immediately:

$$V(S_t) \leftarrow V(S_t) + \alpha \underbrace{\left[ R_{t+1} + \gamma V(S_{t+1}) - V(S_t) \right]}_{\delta_t \text{ (TD Error)}}$$
The Bellman Link: Notice that the TD error $\delta_t = R_{t+1} + \gamma V(S_{t+1}) - V(S_t)$ is a sample realization of the Bellman expectation deficit: $$\mathbb{E}_\pi[\delta_t \mid S_t = s] = \mathcal{T}^\pi V(s) - V(s)$$ When $V = v_\pi$, the expected TD error is identically zero.

The term $R_{t+1} + \gamma V(S_{t+1})$ is the TD target. Unlike Monte Carlo, TD substitutes the unknown sum of future rewards with its current estimate $V(S_{t+1})$. This process—updating an estimate from other existing estimates—is called bootstrapping.

Bias, Variance, and the Credit Assignment Dial

The comparison between Monte Carlo and TD(0) represents the quintessential bias-variance trade-off in reinforcement learning:

Monte Carlo Target Zero Bias · High Variance

Updates toward realized return $G_t$. Unbiased because it records nature directly, but noisy because every random transition in the trajectory compounds.

Target Form $G_t = \sum_{k=0}^\infty \gamma^k R_{t+k+1}$
Episode Constraint Must terminate (no online loops)
Convergence Speed Slow (demands small step size $\alpha$)
TD(0) Bootstrapped Target Low Variance · Biased

Updates toward $R_{t+1} + \gamma V(S_{t+1})$. Inherits bias from current estimate $V$, but dramatically suppresses variance by truncating trajectory noise.

Target Form $R_{t+1} + \gamma V(S_{t+1})$
Episode Constraint Fully online (continuous tasks)
Convergence Speed Fast (tolerates aggressive $\alpha$)

$n$-Step TD: Unifying the Continuum

TD(0) and Monte Carlo are not incompatible opposites; they are the extreme anchor points of a continuous spectrum parameterized by the planning horizon $n$:

$$G_t^{(n)} = R_{t+1} + \gamma R_{t+2} + \dots + \gamma^{n-1} R_{t+n} + \gamma^n V(S_{t+n})$$

As $n$ ranges from $1$ to $\infty$, $n$-step TD sweeps smoothly from maximum bootstrapping (TD(0)) to zero bootstrapping (Monte Carlo). Intermediate values like $n=3$ or $n=5$ frequently strike the optimal empirical trade-off: accumulating enough real empirical rewards to dilute initial estimation bias, while cutting off the tail before trajectory variance explodes.

From Value to Policy: On-Policy vs. Off-Policy Control

When the environment transition dynamics are unknown, a state-value function $V(s)$ cannot be translated into actions without a model (you cannot evaluate $\arg\max_a \sum_{s'} \mathcal{P}(s' \mid s, a) V(s')$ if you cannot predict where actions land). Control therefore demands learning state-action values $Q(s, a)$.

SARSA: On-Policy Control

SARSA evaluates and improves the policy that is actually being executed (including its random exploratory deviations):

Algorithm · SARSA (State-Action-Reward-State-Action) On-Policy TD Control
  1. In state $S_t$, choose action $A_t$ using behavior policy (e.g., $\varepsilon$-greedy on $Q$).
  2. Execute $A_t$, observe reward $R_{t+1}$ and next state $S_{t+1}$.
  3. In state $S_{t+1}$, sample next action $A_{t+1} \sim \pi(\cdot \mid S_{t+1})$.
  4. Perform on-policy update: $$Q(S_t, A_t) \leftarrow Q(S_t, A_t) + \alpha \left[ R_{t+1} + \gamma Q(S_{t+1}, A_{t+1}) - Q(S_t, A_t) \right]$$
  5. Set $S_t \leftarrow S_{t+1}$, $A_t \leftarrow A_{t+1}$, and repeat.

Q-Learning: Off-Policy Control

Watkins (1989) formulated Q-Learning by severing the link between the policy being executed and the policy being evaluated:

Algorithm · Q-Learning (Watkins, 1989) Off-Policy TD Control
  1. In state $S_t$, choose action $A_t$ using behavior policy (e.g., $\varepsilon$-greedy on $Q$).
  2. Execute $A_t$, observe reward $R_{t+1}$ and next state $S_{t+1}$.
  3. Perform off-policy update assuming greedy optimality next: $$Q(S_t, A_t) \leftarrow Q(S_t, A_t) + \alpha \left[ R_{t+1} + \gamma \max_{a} Q(S_{t+1}, a) - Q(S_t, A_t) \right]$$
  4. Set $S_t \leftarrow S_{t+1}$, and repeat.

The operational distinction lies in the target: SARSA accounts for the exploratory mistakes it knows it will make, whereas Q-Learning assumes counterfactual perfection from the next step onward.

The Cliff Walking Crucible: Safe Paths vs. Fragile Optima

The philosophical divergence between SARSA and Q-Learning is illuminated by the classic Cliff Walking environment ($4 \times 12$ grid). Watch how the two agents evolve during exploration:

  • Q-Learning (Red Disk): Learns the mathematically optimal shortest path directly adjacent to the cliff edge. Because it uses $\max_a Q(s', a)$, its target presumes it will never step off. However, because it explores with $\varepsilon = 0.1$, an accidental random perturbation inevitably sends it plummeting into the abyss, resulting in terrible training-time cumulative returns.
  • SARSA (Green Disk): Learns a conservative, roundabout detour over the top of the grid. Because its update incorporates $Q(S_{t+1}, A_{t+1})$ drawn from its actual exploratory policy, it explicitly penalizes states close to the edge that are vulnerable to accidental slip-ups.
Atlas Entry #10 · The Behavior-Target Mismatch

Training return reflects the behavior policy, not the greedy capacity of the learned values. Q-Learning performs poorly during training due to exploratory cliff falls, yet if frozen and evaluated greedily ($\varepsilon = 0$), it executes the optimal 13-step path flawlessly.

Never evaluate an algorithm solely by its exploratory training reward: on-policy methods maximize online safety, while off-policy methods discover the uncompromised optimum.

Failure Modes: Step-Size Sensitivity & Divergence

Temporal-Difference learning abandons the safety of Monte Carlo sample averaging. This speed comes at the cost of two classical failure modes:

Atlas Entry #11 · Step-Size Hypersensitivity

Unlike Monte Carlo, where errors diminish asymptotically under simple empirical averaging, TD updates chase a moving target ($R_{t+1} + \gamma V(S_{t+1})$).

If the learning rate $\alpha$ is too high, errors in downstream estimates propagate backward, causing values to oscillate violently. If $\alpha$ is too small, bootstrapping moves like molasses. The sweet spot of $\alpha$ is highly sensitive to the spectral radius of the transition matrix and the reward scale.

The Deadly Triad (Sutton & Barto)

When extending TD from tabular lookups to function approximation (such as deep neural networks), convergence is no longer guaranteed. Combining three elements simultaneously can trigger catastrophic numerical divergence:

  1. Function Approximation: Parametric representation $V_\theta(s)$ or $Q_\theta(s, a)$;
  2. Bootstrapping: Updating from downstream estimates rather than terminal returns;
  3. Off-Policy Learning: Training on data collected under a different distribution.

Breaking any one leg of the triad restores stability: Monte Carlo drops bootstrapping; on-policy SARSA drops off-policy distribution shifts; tabular methods drop function approximation.

Appendix · Minimal NumPy Tabular TD Control 35 Lines Python 
import numpy as np

class QLearning:
    """Off-policy TD control for discrete state-action spaces."""
    def __init__(self, num_states, num_actions, alpha=0.1, gamma=0.99, epsilon=0.1):
        self.Q = np.zeros((num_states, num_actions))
        self.alpha = alpha
        self.gamma = gamma
        self.epsilon = epsilon
        self.num_actions = num_actions

    def act(self, state):
        if np.random.rand() < self.epsilon:
            return np.random.randint(self.num_actions)
        return int(np.argmax(self.Q[state]))

    def update(self, s, a, r, next_s, done):
        target = r if done else r + self.gamma * np.max(self.Q[next_s])
        self.Q[s, a] += self.alpha * (target - self.Q[s, a])

class SARSA(QLearning):
    """On-policy TD control evaluating the exploratory policy."""
    def update(self, s, a, r, next_s, next_a, done):
        target = r if done else r + self.gamma * self.Q[next_s, next_a]
        self.Q[s, a] += self.alpha * (target - self.Q[s, a])

Further Reading

These classical publications established the theoretical foundations of temporal-difference learning:

  1. Sutton & Barto · Reinforcement Learning: An Introduction
    Chapter 6: Temporal-Difference Learning. The definitive pedagogical exposition of TD error, bootstrapping, and Cliff Walking dynamics.
  2. Sutton (1988) · Learning to predict by the methods of temporal differences
    Machine Learning. Introduced the TD($\lambda$) family and proved linear convergence for absorbing Markov chains.
  3. Watkins & Dayan (1992) · Q-learning
    Machine Learning. The rigorous proof of off-policy convergence to optimal action-values with probability 1.
  4. Rummery & Niranjan (1994) · On-line Q-learning using connectionist systems
    Cambridge University Technical Report. Formulated the SARSA algorithm for online state-action control.
  5. Tsitsiklis & Van Roy (1997) · An analysis of temporal-difference learning with function approximation
    IEEE Transactions on Automatic Control. Clarified the stability bounds and divergence risks of TD under linear function approximation.
